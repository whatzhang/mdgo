# 看板标准格式参考

> 本文件是看板 Markdown 的**标准格式**
> 修改看板时以此为模板；标注了每部分在软件中的解析归属（列 / 卡片 / 子任务 / 正文）。

## 标准格式完整示例

```markdown
---
kanban-plugin: basic
---

## 待办                                    ← 列
- [ ] 任务1                                 ← 卡片（未完成）
    - 负责人: {{负责人}}                     ← 子任务/属性（4 空格缩进 - 键: 值）
    - 优先级: 🔴 高 / 🟡 中 / 🟢 低           ← 子任务/属性
    - 预计时间: X小时/X分钟                  ← 子任务/属性
    - 截止时间: YYYY-MM-DD                  ← 子任务/属性

## 进行中                                   ← 列
- [ ] 进行中的任务1                          ← 卡片
                                            ← （空行分隔正文）
    | 子任务 | 进度 | 负责人 |阻塞因素 |       ← 卡片正文（4 空格缩进表格）
    | :--- | :--- | :--- | :--- |
    | 子任务1 | 10% | 耄耋 | 技术原因 |
    | 子任务2 | 90% | 刀盾 | 流程依赖 |
                                            ← （空行）
    - 截止时间: YYYY-MM-DD                  ← 子任务（正文表格之后）
- [ ] 进行中的任务2                          ← 卡片
                                            ← （空行）
    ```python                              ← 卡片正文（4 空格缩进代码块）
    def bubble_sort(arr):
        n = len(arr)
        for i in range(n):
            for j in range(0, n - i - 1):
                if arr[j] > arr[j + 1]:
                    arr[j], arr[j + 1] = arr[j + 1], arr[j]
        return arr
    ```
                                            ← （空行）
- [ ] 进行中的任务3流程图                     ← 卡片
                                            ← （空行）
    ```mermaid                             ← 卡片正文（4 空格缩进 mermaid 代码块）
    graph LR
        A[任务1] --> B[任务2] --> C[任务3] 
        B --> D[任务4]
    ```

## 已完成                                   ← 列
- [x] 已完成的任务                           ← 卡片（已完成）
- [x] 任务2                                 ← 卡片（已完成）
    - [x] 子任务1                            ← 子任务（4 空格缩进，已完成）
    - 任务                                   ← 子任务（4 空格缩进，无勾选）
    - [x] 子任务2                            ← 子任务（已完成）
```

## 解析归属速查（软件规则）

| 正则/规则 | 归属 |
|---|---|
| 行首 `## ` | 列标题 |
| 行首 `- ` / `* `（无缩进） | 卡片（`- [ ] `=未完成、`- [x] `=已完成、`- `=无勾选） |
| 任意缩进 + `- `（即 `    - ...`） | 子任务/属性行（`- 键: 值` 用作属性；`[ ]`/`[x]` 用作可勾选子任务） |
| 4 空格缩进的其他内容（表格 `\| \|`、``` 代码块、文本） | 卡片正文（Markdown 渲染） |
| 8 空格缩进 | 子任务正文（嵌套在该子任务下） |

## 生成器输出格式（写回时对齐）

```
## 列标题
- [x] 卡片内容
    卡片正文（4 空格缩进，前后空行）
    - [x] 子任务
        子任务正文（8 空格缩进，前后空行）
```

- 卡片/子任务勾选：`checked=true` → `[x]`，`false` → `[ ]`，无勾选 → 不带 `[ ]` 前缀
- 列与列之间空一行；连续空行会被软件合并为单个空行
- frontmatter 与 `%% kanban:settings` 尾部块原样保留
