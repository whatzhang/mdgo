## 适用场景
- 用户要求查看/整理看板：列出列与卡片、新增卡片、勾选完成、移动卡片到其他列、删除卡片、新增/重命名列、补充卡片属性（负责人/优先级/截止时间等）
- 看板数据是**标准 Markdown 文件**（Obsidian kanban-plugin 格式），直接用 `read` 读取、修改文本后 `write`/`edit` 写回即可，无需专用工具

## 工作流程
1. **定位文件**：优先用用户给出的路径；未给时用 `ls`/`glob` 在知识库内查找含 `kanban-plugin` frontmatter 的 `.md` 文件，向用户确认后再操作
2. **读取**：用 `read` 读取看板文件全文
3. **修改**：按下方「格式规约」在文本上直接编辑
4. **写回**：整体改动用 `write` 覆写全文；局部小改动（单个勾选/单个卡片）用 `edit` 精准替换
5. **汇报**：向用户说明改动（新增/勾选/移动了哪些卡片）

## 格式规约（与软件解析/生成逻辑一致）

**结构骨架**

```markdown
---
kanban-plugin: basic
---

## 列标题
- [ ] 卡片标题
    - 负责人: {{负责人}}
    - 截止时间: YYYY-MM-DD

%% kanban:settings
{"display-card-count":true}
%%
```

**层级界定（解析器规则，必须遵守）**

| 元素 | 写法 | 说明 |
|---|---|---|
| 列 | 行首 `## 列标题` | 不能缩进 |
| 卡片 | 行首 `- [ ] 标题`（未完成）/ `- [x] 标题`（已完成）/ `- 标题`（无勾选） | 行首无缩进 |
| 子任务/属性 | **4 空格缩进** + `- [x] 内容` 或 `- 键: 值` | 属性行（负责人/优先级/预计时间/截止时间）用 `- 键: 值`；可带 `[ ]`/`[x]` 勾选 |
| 卡片正文 | **4 空格缩进**的表格（`\| ... \|`）、代码块（``` ``` ```）、普通文本 | 支持 Markdown 渲染（表格/代码块/图表） |
| 子任务正文 | **8 空格缩进** | 嵌套在该子任务行之下 |

**顺序约束（重要）**：卡片标题行 →（可空行）→ **4 空格缩进的正文** → **4 空格缩进的子任务行**
- 软件解析时：卡片标题行之后、第一个缩进 `- ` 行之前的内容算作**卡片正文**；其后每个缩进 `- ` 行算作**子任务**
- 因此表格/代码块等正文**必须写在子任务行之前**，否则会被归入子任务正文
- 移动卡片时，其下的缩进子任务/正文必须整体一起移动

**勾选**：`[ ]`=未完成、`[x]`=已完成；勾选卡片时软件会联动其子任务勾选状态

**保留**：frontmatter（`---\nkanban-plugin: basic|board\n---`）与文件尾 `%% kanban:settings` 设置块必须原样保留；列/卡片之间可用空行分隔（软件会自动合并多余空行）

## 注意事项
- 不伪造卡片内容：用户未提供的新卡片文字要如实向用户确认后创建
- 写回前与用户确认目标文件路径（不要在未确认时覆写已有看板）
- 读取或写回失败时，如实返回失败原因，不编造看板内容、不重复无效调用
