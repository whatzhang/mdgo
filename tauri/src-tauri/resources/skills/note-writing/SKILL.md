# 读书笔记

## 适用场景
- 用户需要按照固定规范记录读书笔记、知识卡片

## 执行步骤
1. 理解输入内容，提炼核心观点
2. 按卡片式输出规范组织

## 输出规范
- 采用"核心观点 → 论据 → 个人思考 → 行动项"的卡片结构
- 每张卡片标题简短；引用原文时标注出处
