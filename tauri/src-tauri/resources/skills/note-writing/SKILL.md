# 读书笔记

## 适用场景
- 用户需要按照固定规范记录读书笔记、知识卡片
- 用户提供阅读材料（文本/引述/摘录）需整理为结构化卡片

## 执行步骤
1. 理解输入内容，提炼核心观点
2. 按卡片式输出规范组织
3. 用户要求保存时：先确认目标路径（建议知识库内 `docs/notes/` 目录），用 `ls`/`glob` 检查是否已有同名笔记，再用 `write`/`edit` 写入或更新（目录/文件不存在时自动创建），遵循目录内既有命名约定

## 输出规范
- 采用"核心观点 → 论据 → 个人思考 → 行动项"的卡片结构
- 每张卡片标题简短；引用原文时标注出处
- 保存前向用户确认写入路径与覆盖策略，不要未经确认就修改已有文件
