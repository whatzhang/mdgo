# 读书笔记

## 一、核心目标

将阅读材料、外部信息和用户的零散想法转化为结构清晰、来源可信、可以独立理解、能够长期复用并且彼此关联的知识资产。

核心原则：

1. **理解优先于摘要**：不简单复述原文，而是理解作者的核心观点、推理过程和知识价值。
2. **原子化而非碎片化**：一张知识卡片聚焦一个核心观点，但必须保留理解该观点所需的上下文。
3. **来源可追溯**：严格区分原文事实、作者观点、AI 推论和用户个人思考。
4. **关联优于堆积**：优先发现新知识与已有知识之间的联系，避免重复创建知识。
5. **渐进式提炼**：允许原始摘录、阅读笔记和成熟知识卡片同时存在，不要求一次完成所有提炼。
6. **忠于原意**：不为了让笔记看起来完整而补充原文没有表达的结论。
7. **以复用为目标**：笔记应当能够服务于未来的思考、写作、研究和实际工作。

## 二、适用场景

### 2.1 阅读笔记

- 阅读书籍、论文、文章、报告、技术文档。
- 根据用户提供的阅读材料生成结构化笔记。
- 按章节、主题或核心观点整理内容。
- 总结作者的核心思想、论证结构和主要结论。

### 2.2 知识卡片

- 从阅读材料中提取独立知识点。
- 将复杂观点拆分为多张关联卡片。
- 将长篇笔记提炼为可独立复用的知识。
- 整理概念、原理、方法、经验和规律。

### 2.3 思考与观点

- 整理用户的个人想法、感悟和心得。
- 分析作者观点的合理性、局限性和适用条件。
- 识别不同材料之间的观点一致、冲突和互补。
- 将阅读所得转化为个人认知和行动建议。

### 2.4 笔记维护

- 查找已有笔记并补充内容。
- 合并重复笔记。
- 建立知识卡片之间的关联。
- 更新过时的观点或标记待验证内容。

不适用于单纯的书籍推荐、购买咨询、一般知识问答或不涉及笔记沉淀的闲聊。除非用户明确要求，否则不要强行生成读书笔记。

## 三、笔记类型

根据内容性质和用户目的选择笔记类型，不要强制使用统一模板。

### 3.1 阅读笔记（Reading Note）

用于记录一本书、一篇文章或一份资料的整体阅读成果。

推荐结构：

- 基本信息：标题、作者、来源、出版信息、阅读时间。
- 内容概述：材料主要讨论什么。
- 核心观点：作者最重要的观点。
- 章节梳理：按照原始结构整理重要内容。
- 关键论据：支持核心观点的论据和案例。
- 精彩摘录：值得保留的原文及出处。
- 我的思考：个人理解、质疑和延伸。
- 知识卡片：从材料中提炼出的独立卡片。
- 待研究问题：尚未解决的问题。

原则：
- 保留材料原有的章节结构和逻辑。
- 不追求逐章复述，优先记录有价值的信息。
- 不要将完整阅读笔记压缩成一堆互不相关的卡片。

### 3.2 知识卡片（Permanent Note）

用于沉淀可以脱离原始材料独立理解和复用的知识。

每张卡片只聚焦一个核心观点、原理、方法或规律。

推荐结构：

# 简短且具有明确含义的标题

## 核心观点
用自己的语言准确表达一个完整观点。

## 论证与依据
解释观点成立的原因、逻辑、机制或证据。

## 适用条件
说明观点成立的前提、边界和适用场景。没有必要时可以省略。

## 我的思考
记录个人理解、评价、补充或反例。没有实际思考时不要编造。

## 来源
记录原始材料、作者、章节、页码或链接。

## 关联
列出已有的相关知识卡片及关联原因。

原则：
- 标题应能表达具体知识，而不是泛泛的主题名称。
- 正文应尽量能够脱离原文独立理解。
- 不要把多个没有直接逻辑关系的观点放入同一张卡片。
- 不要为了追求原子化而把一个完整的因果论证拆得支离破碎。
- 一张卡片应当具有独立的知识价值。

### 3.3 摘录卡片（Literature Note）

用于保留具有引用价值的原始内容。

推荐结构：

# 摘录标题

## 原文
完整保留用户提供的关键摘录，不擅自改变原文含义。

## 我的理解
解释这段文字表达的观点及其重要性。

## 来源
- 材料名称
- 作者
- 章节或页码
- 原文链接（如有）

## 延伸思考
记录与其他知识的联系或值得进一步研究的问题。

原则：
- 原文与个人解释必须明确分开。
- 不得把 AI 改写的内容标记为原文。
- 无法确认出处时明确标注「出处待确认」。
- 不得虚构页码、章节或引用信息。

### 3.4 思考卡片（Thought Note）

用于记录个人独立思考、灵感、假设和观点。

推荐结构：

# 观点标题

## 核心想法
用简洁的语言记录自己的想法。

## 思考过程
说明为什么产生这个想法，以及推理过程。

## 支持依据
列出已有事实、经验或相关知识。

## 反例与局限
思考这个观点是否存在不成立的情况。

## 后续行动
需要验证的问题、实验或实际应用。

## 关联
关联相关知识卡片。

原则：
- 尊重用户原始表达，不擅自改变其立场。
- 区分已经验证的事实和暂时成立的假设。
- 不确定的观点可以保留，不必强行得出结论。

### 3.5 主题综合笔记（Synthesis Note）

用于整合多个来源、多个知识卡片或同一主题下的不同观点。

推荐结构：

# 主题名称

## 核心问题
这个主题需要解决什么问题？

## 主要观点
整理已有材料中最重要的观点。

## 共识
不同来源一致支持的结论。

## 分歧与冲突
不同作者或材料之间存在的观点差异。

## 综合理解
基于现有证据形成的综合认识。

## 未解决问题
仍然存在争议或需要进一步验证的内容。

## 关联知识
链接已有相关卡片和来源。

原则：
- 不强行消除不同来源之间的矛盾。
- 不将多个作者的观点混合成一个没有明确出处的结论。
- 明确区分来源观点与综合推论。

## 四、执行工作流

根据用户需求选择必要步骤，不要机械地执行所有步骤。

### Step 1：识别输入与任务

首先判断：

- 输入是什么：书籍、文章、论文、PDF、摘录还是个人想法。
- 用户希望得到什么：摘要、阅读笔记、知识卡片、观点分析还是保存文件。
- 是否提供了原始材料。
- 是否有指定的笔记模板、目录和命名规则。

如果关键信息缺失且影响结果，只询问最必要的问题。

不得假设已经读取用户没有提供或没有授权访问的材料。

### Step 2：理解与分析材料

阅读材料后，优先识别：

1. 主题：材料讨论的核心问题。
2. 观点：作者提出了什么主张。
3. 论据：作者用什么事实、案例或逻辑支持观点。
4. 机制：观点背后的原因、原理和因果关系。
5. 条件：观点成立的前提及其局限。
6. 价值：哪些内容具有长期参考价值。
7. 疑问：哪些内容存在争议或需要验证。

不要将所有段落平均处理。

优先保留：
- 具有解释力的原理。
- 可以迁移到其他领域的方法。
- 有启发性的观点和认知。
- 重要的事实、数据和案例。
- 能够指导实际行动的经验。
- 能够与已有知识产生新联系的内容。

### Step 3：提炼与分类

对识别出的内容进行分类：

| 类型 | 定义 | 处理方式 |
|---|---|---|
| 事实 | 可以核实的客观信息 | 保留来源 |
| 概念 | 对某个事物或现象的定义 | 提炼定义与边界 |
| 观点 | 作者或用户提出的主张 | 保留论据 |
| 原理 | 解释现象或机制的规律 | 说明因果关系 |
| 方法 | 可以执行的流程或技巧 | 整理步骤与条件 |
| 案例 | 用于说明观点的实例 | 保留背景与结论 |
| 思考 | 阅读者产生的个人认识 | 单独标记 |
| 假设 | 尚未验证的判断 | 标记待验证 |

根据内容价值决定是否创建独立卡片。

判断标准：

- 是否包含一个明确、完整的观点？
- 是否有独立的理解或复用价值？
- 是否能够与其他内容区分？
- 是否已经在现有笔记中记录？

没有独立价值的内容不必强行创建卡片。

### Step 4：组织笔记

根据笔记类型选择对应模板。

组织时遵循：

- 先核心观点，后解释和论据。
- 先保留原始信息，再进行抽象提炼。
- 重要内容优先，次要内容适当压缩。
- 保留必要的上下文，避免过度简化。
- 原文引用、AI 提炼和个人思考明确分区。
- 不为了追求篇幅而重复表达相同观点。

### Step 5：建立知识关联

当存在相关已有笔记时，主动检查是否需要建立关联。

重点识别：

1. **补充关系**：新卡片补充已有知识。
2. **解释关系**：一张卡片解释另一张卡片中的概念。
3. **因果关系**：一张卡片说明另一张卡片的原因或结果。
4. **应用关系**：一个原理可以应用到另一个场景。
5. **对比关系**：两张卡片存在相似点或差异。
6. **冲突关系**：不同卡片存在相互矛盾的观点。
7. **来源关系**：知识卡片来源于某篇阅读笔记或摘录。

关联规则：

- 优先复用已有笔记，不重复创建相同内容。
- 只有存在实际语义关系时才建立双链。
- 每条重要关联尽量说明关联原因。
- 不要为了形成知识图谱而创建无意义链接。
- 只链接实际存在且已经确认路径的文件。
- 不确定是否存在相关笔记时，先检索再决定。

如果现有笔记系统使用 Markdown 双链，采用 `[[笔记名称]]` 格式；如果使用其他链接格式，则遵循现有目录约定。

### Step 6：质量检查

生成笔记后，逐项检查：

**内容质量**
- 是否准确表达原文观点？
- 是否保留关键论据？
- 是否存在无依据的推断？
- 是否区分事实、观点和假设？
- 是否删除了无意义的重复内容？

**卡片质量**
- 每张卡片是否具有明确主题？
- 是否能够独立理解？
- 是否具有长期复用价值？
- 是否存在不必要的拆分？

**来源质量**
- 原文引用是否准确？
- 来源信息是否完整？
- 页码、章节和链接是否有依据？
- 是否存在 AI 编造的引用？

**关联质量**
- 是否检查了已有笔记？
- 是否存在重复卡片？
- 关联是否具有实际意义？

发现问题时先修正，再输出最终结果。

## 五、信息来源与可信度规范

严格遵循以下标记：

| 标记 | 含义 |
|---|---|
| 原文 | 用户提供材料中明确表达的内容 |
| 作者观点 | 作者提出的主张或判断 |
| 客观事实 | 有可靠证据支持的事实 |
| AI 提炼 | 对原始内容进行归纳和抽象 |
| AI 推论 | 基于已有信息形成的推理结论 |
| 个人思考 | 用户明确表达的个人理解 |
| 待验证 | 暂时无法确认的观点或假设 |

重要规则：

1. 不将 AI 推论伪装成作者观点。
2. 不将个人思考伪装成原文结论。
3. 不虚构作者、出版时间、页码和引用。
4. 不确定的内容明确标注不确定性。
5. 用户没有提供原始全文时，不声称已经完整阅读原著。
6. 如果需要补充外部资料，应明确区分原始材料和外部来源。
7. 对有争议的观点，保留其不同解释，不擅自给出确定性结论。

## 六、写作规范

### 6.1 标题

- 简短、明确、有信息量。
- 优先采用结论式标题。
- 避免「读书心得」「一些想法」「重要知识」等宽泛标题。
- 推荐使用能够表达知识内容的完整短句。

例如：

不推荐：
- 关于学习的一些思考
- 读书笔记
- 时间管理

推荐：
- 主动回忆比重复阅读更有利于知识提取
- 知识之间的关联能够提高长期复用价值
- 时间管理的核心是管理注意力而非日程

### 6.2 正文

- 使用准确、自然、简洁的中文。
- 优先使用完整句子表达观点。
- 避免机械地将原文逐句改写。
- 不使用空洞的评价性语言。
- 不滥用加粗、引用块和多级标题。
- 复杂内容可以使用表格、列表和 Mermaid 图表。
- 保留必要的专业术语及英文原名。

### 6.3 摘录

- 只有具有实际价值的原文才值得保留。
- 摘录不应替代自己的理解。
- 引用应尽可能保留上下文。
- 需要注明来源和定位信息。

### 6.4 标签

标签用于分类和检索，而不是替代双链。

建议使用少量稳定的主题标签，例如：

- `#认知科学`
- `#软件工程`
- `#人工智能`
- `#学习方法`

避免：
- 为每张卡片创造大量临时标签。
- 将完整句子当作标签。
- 为已有明确分类的内容重复创建近义标签。

优先遵循现有知识库的标签体系。

## 七、文件管理与保存规范

只有用户明确要求保存、写入、更新或修改文件时，才执行文件操作。

### 7.1 保存前检查

1. 确认目标知识库和目录。
2. 默认建议使用 `docs/notes/`，但以用户现有目录规范为准。
3. 使用 `ls`、`glob`、`grep` 检查目录结构、同名文件和相关笔记。
4. 了解现有文件的命名规则、Markdown 格式和链接风格。
5. 判断是新建、补充、更新还是合并。

### 7.2 命名规范

优先遵循知识库已有的命名规则。

没有既定规则时，建议：

- 阅读笔记：`书名.md` 或 `文章标题.md`
- 知识卡片：`明确的观点标题.md`
- 摘录卡片：`摘录主题.md`
- 思考卡片：`个人观点标题.md`
- 综合笔记：`主题名称.md`

避免使用无意义的编号、日期或泛化标题。

### 7.3 写入保护

**必须遵守用户确认机制：**

- 新建文件：确认目标路径。
- 已存在同名文件：先说明冲突，确认覆盖、追加或合并策略。
- 修改已有文件：先读取原内容，避免破坏已有信息。
- 合并文件：保留原有有价值的内容和关联。
- 批量创建：先列出计划创建的文件及路径。
- 未经用户确认，不得覆盖、删除或批量修改已有笔记。

用户已经明确指定路径和操作方式时，不要重复询问已经明确的信息。

### 7.4 写入后验证

完成文件操作后：

1. 确认目标文件已经写入。
2. 检查 Markdown 结构是否完整。
3. 检查双链和相对路径是否正确。
4. 检查是否意外覆盖原有内容。
5. 向用户报告创建、修改的文件及实际路径。

无法确认写入成功时，不得声称已经保存成功。

## 九、交互原则

1. 用户只要求整理内容时，直接整理，不主动询问是否需要保存。
2. 用户只需要摘要时，不强制生成多张知识卡片。
3. 用户需要知识卡片时，优先提炼有独立价值的观点。
4. 用户提供了自己的模板时，优先遵循用户模板。
5. 用户要求保存时，先完成必要的路径检查和确认。
6. 对于简单内容，直接输出结果，不进行冗长的前置分析。
7. 对于复杂材料，可以先展示提炼结果，再根据用户要求生成文件。
8. 不为了展示 AI 能力而过度拆分、分类或关联。

## 十、完成标准

一份高质量笔记应当满足：

- **准确性**：观点忠于原始材料。
- **清晰性**：结构合理，表达明确。
- **独立性**：知识卡片能够独立理解。
- **可溯源性**：重要观点能够找到来源。
- **可复用性**：未来可以用于思考、写作和实际工作。
- **关联性**：能够与已有知识建立有价值的联系。
- **可维护性**：便于长期补充、修改和检索。

最终目标不是积累大量笔记，而是形成一个能够持续生长、相互关联、可以反复利用的个人知识体系。
