| # | 对应 PRD | 操作 | 预期 |
|---|---|---|---|
| P0-1 | 2/3 浮层 | 打开 md 文件 → 点 FAB AI 头像 | 弹出面板宽高约窗口 2/3、居中；Esc/点遮罩可关；二次打开位置尺寸稳定 |

| P0-10 | 快/深档 | 在“自动/快速/深度”间切换并发送 | 请求带对应 reasoning（深度→high），正常生成 |
| P0-11 | DocAgent 内核 | （开发者）`doc_read_meta`/`doc_build_context` 返回值 | 章节带 `line_start/end`；预算截断后含省略清单 |
| P0-12 | 主 Agent 调用 | 在主 Agent 页提问：“用 doc_agent 分析 xx.md” | 工具卡片出现 `doc_agent`，返回带引用结论；可在结果 id 上要求继续读全量 |

## 2. 受限/待补（如实记录）
- 未关联文件（关闭开关）时发送被拦截并提示去 Agent 页（产品决策：整库问答归主 Agent 页）。
- 会话历史按文件聚类目前为前端 localStorage 映射（服务端仅 `type='doc'`）；跨设备/清缓存即丢失，P1 做服务端 `file_key`。
- 引用定位基于段落/行号锚点与现网 openSourceAndLocate；若选区内文本过短（<2 字符）定位会退化提示。
- 双流并存未支持：浮层与主 Agent 页共享单实例流状态，同一时刻只能一处生成（产品一致）。

## 5. P1 验收用例（2026-09 批次）

| # | 对应 | 操作 | 预期 |
|---|---|---|---|
| P1-1 | 存为新笔记 | 回答后点“存为笔记” | 自动命名 `<文档>-小助手笔记-<日期>.md`，正文带来源回链，落入所选目录 |
| P1-2 | 会话即资产/历史 | 多轮后点“存会话”；关闭再开同文件 | 导出含全部轮次；历史下拉列出本文档 doc 会话并可恢复继续 |
| P1-3 | 选区动作格 | 选中文段后打开小助手 | 出现“选区（优先）”动作格，执行解释/润色/翻译/待办/总结选区 |
| P1-4 | @提及/@文件夹 | 输入 `@其它.md` 或 `@子目录/` 提问 | 关联文档/目录内容进入回答并引用；总量 ≤3、目录 ≤2 |
| P1-5 | 结构化输出 | 点“大纲/脑图”快捷动作；“预览”任意代码块 | 大纲为多级 Markdown；脑图为 mermaid mindmap；预览可渲染/插入 |
