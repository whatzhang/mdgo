## 维护约定

1. **新增文档**：请使用中文文件名，并在本索引注册分类与定位。
2. **修改代码**：触及检索链路先对照 `混合检索逻辑契约.md`；触及分块预算先对照 `分块 Token 预算设计.md`。
3. **文档改名**：必须同步更新本索引、其他文档的引用、以及 `retrieval_eval/expected.jsonl` 中的相关文档路径。
4. **删除文档**：删除后必须清理所有引用（禁止悬空引用），并在本索引移除条目。
